Overview

Sentiment Mini is a fictional baseline for exploring positive and negative sentiment in short reviews.

This learning resource demonstrates how to document a model. The metrics and configuration below are sample data, not results from a trained model.

Usage example

This Python example describes a configuration. It does not load weights or run predictions.

import json

configuration = {"name": "Sentiment Mini", "version": "1.0", "framework": "PyTorch", "task": "text-classification", "labels": ["negative", "positive"]}
print(json.dumps(configuration, indent=2))
